The goal of this project is to create a web application using **HTML**, **CSS**, **SQL**, **PHP**, and **JS**.


The application allows students in a cohort to propose an idea, read it, and vote for the ideas of others.

The SQL is running on **Laragon.wamp** in version 8.7.0.0

&#x09;	**/----------------------------------- AI usage -----------------------------------\\**

 The AIs used are Grok, ChatGPT, and Claude. In total, approximately 50 prompts were sent to the AIs for this project. This allowed us to improve our work, as well as our understanding of the code it provided. We also made an effort to understand and conduct our own research before using what the AI ​​gave us, as it occasionally made mistakes.

(Assya = approximately 15 prompt , Djeneba = 2 prompt, Fatima = approximately 30 prompt) 

Response to the question: The risks involved if an AI were to automatically summarize or categorize ideas include:
- A response that is fluid and well-phrased can be entirely incorrect.
- We end up delegating our own reasoning, leading to less personal engagement in the thinking process.
